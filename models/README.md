# Models Directory

Place your custom-trained YOLO11 ball model weights here:
- Recommended path: `models/best.pt`

When "Use Custom Ball Model" is checked in the Streamlit application sidebar, the application automatically looks for `models/best.pt`.
Alternatively, standard pre-trained models (`yolo11n.pt`, `yolo11s.pt`, `yolo11m.pt`) will be automatically downloaded by Ultralytics when selected.
